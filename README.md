# NeerNayan

NeerNayan is an early-warning and decision-support system for water-borne disease risk in rural Northeast India.

It combines health reports, water-quality data, rainfall/flood information, and village-to-water-source connections to:

- Calculate explainable village risk scores
- Trace probable shared contamination sources
- Identify connected villages that may need preventive verification
- Prioritize government action
- Track interventions and outcomes

## Tech Stack

- Frontend: React + Vite
- Backend: FastAPI + Python
- Database: SQLite + SQLAlchemy
- Maps: Leaflet + React-Leaflet
- Charts: Recharts
- Voice Input: Browser Speech Recognition API

## Prototype Data

The prototype dataset combines reference information with illustrative observations for system demonstration.

## Project Flow

Health + Water Quality + Rainfall/Flood + Water-Source Network  
→ Risk Analysis  
→ Probable Source Tracing  
→ Exposure Warning  
→ Action Prioritization  
→ Intervention Tracking
